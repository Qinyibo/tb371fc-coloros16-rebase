## 1) Where `kb_batt_level` is produced

**File (Force REK / tree):** `drivers/hid/i2c-hid/i2c-hid-core.c`  
**Function:** Lenovo HID status-report branch inside `i2c_hid_get_input()` (~L585–673)

Trigger when:
- report type byte `inbuf[2] == 0x06`
- HID vendor Lenovo `0x17EF` and product `PID_KB_LENOVO` **or** `0x6175` (Tab P12 Pro pack)

Actions on that report:
```c
kb_connect = ihid->inbuf[3] & 0x01;          // Online bit
// ...
sprintf(..., "kb_batt_level=%d", ihid->inbuf[9]);  // telemetry only
kobject_uevent_env(...);                           // userspace uevent
dev_err(..., "kb_batt_level: %d\n", ihid->inbuf[9]);
sprintf(versions_info, "MCU:%d,KB:%d,TP:%d,BT:%d,online:%d,...",
        inbuf[4], inbuf[5], inbuf[6], inbuf[16], kb_connect, ...);
```

**Field meaning (from in-tree comments + code):**

| Field | Source | Meaning |
|---|---|---|
| `kb_batt_level` | `inbuf[9]` | Protocol status byte exposed as uevent/log — **not used in any `if` gate**. Compatible with “not a chargeable pack”: treat as MCU-reported level/status nibble, not Android BatteryManager. |
| `KB:` in `KB connected:` log | `inbuf[5]` | Keyboard FW/version channel in `versions_info` string — **also not a gate** |
| `MCU:` | `inbuf[4]` | Host/MCU version channel |
| `online:` / connect | `inbuf[3] & 0x01` | **THE gate** for hidinput_connect/disconnect |
| `status:XX` | full `inbuf[3]` | Bitfield (sysfs `kb_status` docs): bit0 Online, bit1 BT-new, bit2 Dev2, bit3 Cradle, bits4–5 KB state (00 working / 01 sleeping / 10 stop), bit6 TP suspend, bit7 KB HALL |

Sysfs `kb_status` shows `Not connected` iff `kb_connect==0` (bit0 clear) — independent of `inbuf[9]`.
