# TB371FC · ColorOS 16 干净母包重适配

联想小新 Pad Pro 12.7（TB371FC／Snapdragon 870）的 ColorOS 16 重适配源代码归档。目标是尽量接近一加平板原生体验，并保持长期稳定、可维护。

这是独立私有仓库中的工作快照，**不是可刷发行包，也没有宣布流畅度或长期稳定性通过**。当前受阻于设备离线及笔／手机测试条件缺失；本次 Git 更新不操作平板。

## 母包与迁移边界

- 供体：`OPD2413_16.0.10.600(CN01)`，一加平板 2 Pro，Android 16／API 36。
- OTA 标识：`OPD2413_11.C.35_1350_202609120016`；官方服务器来源、元数据签名及与既有官方供体的签名一致性已核验。
- 未证明该版本是当前最新版本，也未证明“金标”营销名称与它有官方一一对应关系。
- 以完整新母包起底，保留必要的 TB 内核、vendor、HAL 及已验证的硬件兼容修复。旧框架、布局和启动补丁不默认继承。
- 系统相机方向已确定为联想 ZUI；不再推进 ColorOS 相机适配。

## 内容

| 路径 | 内容 |
| --- | --- |
| `pen-sharing-compat/` | 新母包手写笔适配源码、vnet 来源及离线候选状态；硬件未验收 |
| `scheduler-compat/` | 原生前台调度服务、SELinux／init 集成、有限时长的第三方应用采集与分析工具 |
| `scheduler-compat/gpu-floor-native-v7/` | 当前 GPU 下限的构建时 init 配置和集成脚本 |
| `ui-compat/native-ui/` | 动画档位、平板布局、设备身份及可选无线电接口的适配工具 |
| `wifi-compat/` | Wi-Fi 固件／HAL 兼容的构建与补丁工具 |
| `speaker-compat/` | 扬声器旋转方向适配源码 |
| `camera-compat-native/` | 相机适配过程中保留的构建工具；其中部分是已停止的探索，不代表当前启用 |
| `compat-framework/` | 已有框架兼容补丁生成器 |
| `kernel/r107-overlay/` | 当前保留的 EROFS 覆盖源码，保留原始版权及 SPDX 声明 |
| `tools/` | 分区差分构建、回退与刷写校验工具源码 |
| `EXPORT-MANIFEST.json` | 导出源文件清单、原始与导出文件哈希及占位符替换记录 |

当前实际状态与证据限制见 [STATUS.md](STATUS.md)。目录保留本地工程结构；历史工具不等于当前启用项，不能按目录顺序批量执行。

## 复现条件

本仓库没有固件、镜像、APK／APEX、平台 JAR／SO、签名私钥、设备日志或完整内核仓库。需在本地准备经核验的官方供体与 TB 材料、已有内核源码、Android SDK／NDK、Java、Python，以及 Linux 镜像处理工具。

脚本保留原工作区路径 `D:/TB371FC-release/clean-rebase-20261104` 及输入哈希校验。它们仍依赖本地中间材料，尚未整理为任意目录的一键构建项目；缺少输入时应补齐真实材料，不能删掉校验或伪造输出继续执行。

- 主机下载、临时文件、缓存和构建输出均放 D 盘；C／E 盘仅可读取已有工具。
- 设备序列号已替换为 `REPLACE_WITH_DEVICE_SERIAL`，局域网地址已替换为文档地址。设备脚本需先审阅并明确目标，不能直接照抄执行。
- 原生调度构建入口为 `scheduler-compat/build-native.py`；需补齐其中明确校验的官方 Binder 库、framework 及接口上下文。
- 性能工具只用于第三方重载应用的有限采集。自动操作结果是诊断数据，不代表用户主观验收。
- 刷写工具源码仅供审阅与复现；仓库没有可直接刷入的镜像，不提供自动刷机工作流。

## 原则

使用真实接口和必要兼容，优先构建时集成；不伪造服务成功、不循环重启、不叠加未经证实的运行时优化。源码检查、构建、启动、功能、性能和长期稳定分别记录。

用户最新顺序：汽水音乐有限处理后，先手写笔与通信共享，再处理竖屏多任务边界，最后推进流畅度。其他小新机型的 ColorOS 方案仅作参考，不能直接移用其内核、boot、vendor_boot 或模块。

内核文件的许可证见 [LICENSES](LICENSES/README.md)。本次归档没有替其余代码统一指定新的开源许可证。

可复算的崩溃字段、指令片段、帧数据和实验条件见[Grok 核验材料](evidence/2026-11-06/README.md)。
